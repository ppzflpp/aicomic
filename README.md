# 飞鱼AI视频导演台

> 🎉 **本项目代码已开源！** 如果有特殊需求（定制功能、私有化部署、二次开发等），欢迎加作者微信 **`ppzflpp`** 沟通定制。

把小说、故事一键变成漫剧 / 短剧视频的本地软件：**改编 → 角色场景 → 分镜出视频 → 组装成片**。
另外还有独立的**图片生成**、**视频生成**两个工作台，不建项目也能直接用。
全程在你自己的电脑上完成，创作内容不上传、不外泄。

**它能做什么**

| 模块 | 干什么 |
|---|---|
| 剧本改编 | 小说 / 故事 → 分集大纲 → 逐集剧本对白 |
| 角色 & 场景 | 角色卡、场景板、装扮变体，保证同一角色跨镜不换脸 |
| 分镜脚本 | 逐镜出首尾帧 → H3 出视频（首尾帧 / 参考图两条支路），列表 / **网格视图**切换，集级光线与声音基调统一 |
| 组装成片 | **片头封面**、字幕、BGM、逐镜响度归一，**视频超分**放大一档，一键导出成片 |
| 图片生成 | 文生图 / 图片编辑 / 图生图，参考图最多 10 张；参考图可一键**反推提示词**；可选**基础模型 / 加速 LoRA / 风格 LoRA**，采样参数随档位自动锁定；风格 LoRA 丢进目录就能用，**自动适配 PEFT 格式、自动读取触发词、自动识别底模架构** |
| 视频生成 | 文生视频 / 首尾帧生视频 / 参考图·参考视频生视频，自动判定模式，可一键转**白膜视频**；可选**动作 / 交互 LoRA**（放目录即可用）；生成后可**回填配置**、**重写提示词** |

**安装只要三步，照着做就行：**

| 步骤 | 做什么 | 去哪看 |
|---|---|---|
| 第一步 | 装**本软件** | 见下方「第一步」 |
| 第二步 | 装 **ComfyUI**（出图 / 出视频的后端） | 见下方「第二步」 |
| 第三步 | 下载**模型文件**（约 93GB） | 见下方「第三步」 |

三步缺一不可，请按顺序做完，就可以开始创作了。

> 装好之后，软件**左侧菜单最底部有一个「? 帮助」**：里面是同样的步骤，但会读取你电脑的真实状态 —— 模型目录设对没有、四个必需文件还缺哪几个、风格 LoRA 认出几个，一眼就能看出差什么。

## 第一步：安装本软件

两种方式，**任选一种**。

下载安装包（`.exe`，约 750MB），双击 → 选个安装目录 → 装好即可。

> 下载地址：网盘「飞鱼AI视频工作台」

按顺序执行下面 4 条命令：

```bash

cd aicomic/comic-studio
npm install
```

```
comic-studio/
  ├── tools/          ← 从网盘下载后放这里
  ├── electron/
  └── src/
```

## 第二步：安装 ComfyUI（必须装）

⚠️ 出图、出视频都是 ComfyUI 在干活。**不管用上面哪种方式装软件，都必须再装一个 ComfyUI**，否则什么图都出不了。

> ⚠️ **必须按下面的顺序做。** ComfyUI 装完只是有了程序，**还要创建一个实例**——本软件把配套节点装进实例里，没有实例就没地方装，出图会报「节点不存在」。

1. 打开官网下载并安装：[comfy.org/download](https://www.comfy.org/download)（版本要 **0.37.0 以上**）
2. 装好后打开 ComfyUI，**新建并启动一个实例**
   名字随便起（比如「飞鱼AI」），**已经有实例的直接用，不用再建一个**
3. 实例启动起来、确认能进界面后，**把 ComfyUI 关掉**
   （下一步要往实例里装节点，关着装、装完再启动，才不会白装一次）
4. 打开本软件 → 设置 → 模型管家 → 点 **「选择 ComfyUI 安装目录…」**
   - 选 **`Comfy Desktop.exe` 所在的文件夹**（一般是 `…\Comfy Desktop`）
   - 或选 **`…\ComfyUI-Installs\<实例名>\ComfyUI`**（含 `main.py` 的那一层）
   - **不要**选到 `models`，也不要选工作区目录
5. 看到**绿色「节点已就绪」**就说明装好了
   （ComfyUI 关着时显示「节点已置备 · 启动后生效」，效果一样）
6. **手动启动 ComfyUI**（或让本软件启动它），然后就可以开始创作了

> 每次使用本软件之前，都要先启动一次 ComfyUI。
> ComfyUI 版本只在它启动后检测——没启动时显示「请先启动 ComfyUI 实例」，启动后几秒内自动变成真实版本，**不会读到别的实例的版本**。
> 如果节点徽标是黄色「已装好 · 需重启 ComfyUI」，把 ComfyUI 关掉再打开一次即可。
> 忘了建实例？软件会在模型管家里直接提示，不会让你反复重选目录。

## 全部装好后：开始创作

1. 先打开 **ComfyUI**，在里面启动一个实例，然后最小化放着
2. 打开**飞鱼AI视频导演台** → 左上角「设置 → 模型管家」→ 批量导入模型文件夹，确认全部变绿
3. 回到主界面 → 点**新建项目**：先选「视频质量」和「视频比例」，软件会自动把对应的画面分辨率标在比例选项上（如「横版 16:9 · 864×480」），不用再单独去填分辨率
4. 选好项目文件夹，就可以开始创作了

顶部状态条会显示文字模型、ComfyUI、ffmpeg 有没有就绪，以及显卡 / 内存占用，一眼就能看出环境是否正常。

> 出完视频后想更清晰：在「组装成片」点 **「超分视频」**，勾选镜头、选好倍率（建议先 2 倍），出来的版本会自动参与成片导出。很吃显存，也慢，可以只挑重点镜头做。

> 想要片头：在「组装成片」标题栏点 **「选封面」**，点「确认」后导出会在正片前插 1 秒封面卡；点「不用封面」随时撤掉。

> 文字创作、出图、出视频需要用到时，软件会自动启动对应的服务，不用你手动开关。

### 只想先出几张图？

左侧 **「图片生成」** 是独立工作台，不用建项目、不用先跑剧本，选好分辨率直接就能出图：

- **不传图** = 文生图；**传了图** = 以图为准重绘；再勾上「**编辑图片**」= 按你的文字指令改这张图；
- 参考图最多 10 张，提示词里用「图1 / 图2 / 图3」引用（页面里有示例可一键填入）；
- 每张参考图下方都有 **「反推提示词」**：点一下，软件用本地大模型读这张图，自动写出画面描述填进提示词框——反推完直接点生成，就得到同风格的图；
- 出图结果会保留分辨率与生成耗时，点图即可放大查看，历史记录按日期归档在 `图片生成\<日期>\` 下。

### 只想先出个视频？

左侧 **「视频生成」** 是独立工作台，不用建项目、不用先跑剧本，上传素材直接就能出视频：

- 填一句文字，或上传**参考图 / 参考视频 / 首帧 / 尾帧**（可自由组合），系统会**自动判定**走哪种模式（文生视频 / 首尾帧 / 参考生视频），不用你选；
- 时长 4~15 秒可填，视频质量沿用创作台的分档方案（另有「**原生 20 步**」档），比例、分辨率一目了然；
- **动作 / 交互 LoRA**：把 H3 的视频权重丢进模型目录的 `loras\h3-action\`，回到这一页刷新就能选。选它**不会锁住任何质量参数** —— 步数、采样器、加速档还是你自己定的；强度单独可调（0.2~1.2），触发词自动读出来并前置拼进提示词，界面上直接显示真正送出的英文原句；不是 H3 训练的权重会提示并禁用生成按钮；
- 点生成后自动进**任务中心**排队，切菜单、切项目都不中断；
- 每次生成会保存一份「配置快照」，结果上悬停即可**回填配置**、**查看提示词**；开启「**提示词重写**」还能按 H3 官方规范自动优化描述；
- 出片结果保留分辨率、视频时长与生成耗时，历史按日期归档在 `视频生成\<日期>\` 下；
- **白膜视频**：打开开关，参考视频里的人 / 物转成 3D 哑光白模 + 纯绿幕；可**保留原始声音**，时长可切「**自动**」跟随参考视频真实长度（超过 15 秒会自动切段生成再拼接，成片按原时长裁尾）。

| 显存 | 情况 |
|---|---|
| 8-12GB | 出图没问题；出视频建议把分辨率调低一些 |
| 16GB 以上 | 出图、出视频都很顺畅 |

> 出视频要装哪个文件，按你的显卡选（见上方「第三步 ②」）：**50 系显卡选 nvfp4，非 50 系选 int8**。

**视频质量怎么选？** 新建项目里每个质量档都有 **A / B 两个方案**，软件打开时自动识别你显卡的显存，在推荐的那个方案右上角标了金色「推荐」：

- **A 方案**（剪枝模型，16G 以下显存推荐）——更快、更省显存，绝大多数显卡都能顺畅跑；
- **B 方案**（原始模型 + PDD 加速，16G 以上显存推荐）——画质潜力更高、细节更足，适合大显存显卡。

不确定就跟着金色「推荐」走，不会错。挂了动作 / 交互 LoRA 时档位**不会被锁**，想跑多少步就多少步；只想看清 LoRA 本身的效果，选「原生 20 步」即可。

## 最近更新（v0.4.2）

- **图片生成可以选模型了**：「基础模型」和「Turbo 8 步」两个档位任选。选了档位之后，**采样参数会自动锁定**成这一档唯一正确的值（步数、CFG、调度器都变灰不可改），不用自己算，也不会因为手改步数把画面跑坏
- **可选加速 LoRA**：基础模型下挂「Turbo LoRA」，8 步出图，速度大约快四倍；只想稳出图就选「不使用」
- **新增风格 LoRA**：把任意 Qwen-Image 的风格权重丢进模型目录的 `loras\qwen-image\`，回到「图片生成」页刷新就会出现。可以**和加速档同时叠加**，强度用输入框调（0.2 ~ 1.0，默认 0.7）
- **风格 LoRA 全自动适配**：不同平台导出的权重格式不一样，软件会自动转成能用的格式再加载。以前遇到这种格式会**静默丢掉近三成权重**，出图还在、效果只剩七成，界面上一点提示都没有；现在你什么都不用做
- **触发词自动读取**：权重文件里写了触发词就直接用，不用手填；同目录放一个同名 `.json` 可以自定义中文名和备注（`xxx.safetensors.json` 和 `xxx.json` 两种写法都认）
- **挂错底模会拦住**：如果选的 LoRA 不是给 Qwen-Image 训练的（比如 Flux / SDXL 的），界面直接提示并禁用生成按钮，不再白等几十秒才发现没效果
- **CFG 提示**：CFG 设为 1.0 时负面提示词不生效，界面会明确提醒你
- **新增「? 帮助」页**：软件内的一页纸说明书，自带**本机体检** —— 模型根目录是否选对、四个必需文件缺哪几个、风格 LoRA 认出几个，一屏看完。还写了模型该放哪个子目录、LoRA 放完为什么要重启才出现、以及「选中了但画面没变化」这类问题怎么判断。不用另找文档，装完软件就能看
- **视频生成支持动作 / 交互 LoRA**：把 H3 视频权重放进模型目录的 `loras\h3-action\`，回到「视频生成」页刷新即可选择。选它**不锁质量档位**，步数、采样器、加速档照你自己选的跑；强度单独可调，触发词自动读取并前置拼接，界面直接显示真正送出的英文原句；不是给 H3 训练的权重（Flux / SDXL 等）会提示并禁用生成按钮
- **新增「原生 20 步」质量档**：原有档位最快 4 步、最高 8 步，跑动作类 LoRA 时动作交接处容易糊；这一档 20 步、euler 采样，只挂你选的动作 LoRA，专给动作 / 交互类权重用

## 最近更新（v0.4.1）

- **新增「片头封面」**：在「组装成片」标题栏点「选封面」→ 填主标题 / 副标题（可让大模型出 3 条候选）→ 选字体（宋体 / 书法 / 手写）→ 挑角色 / 场景图当参考（第 1 张管环境、第 2 张管人物）→ 一次出 2 张，横版 16:9 或竖版 9:16 任选。点「确认」后导出会自动在正片前插 **1 秒封面**；没确认就不加，点「不用封面」可随时撤掉。也能直接导入一张本地图当封面
- **封面文字直接画进画面**：标题、副标题由模型写进图里（不是后期贴字幕），**字一旦画进像素就抠不出来，改字必须重出图**，所以流程是「先定文案再出图」；内置防错字约束（错字 / 缺笔画 / 粘连 / 乱码），实测多组标题零错字
- **新增「白膜视频」**：在「视频生成」页打开开关，参考视频里的人 / 物会转成 **3D 哑光白模 + 纯绿幕**，适合做二创、抠像、换背景的素材基底。开关一开自动填入内置白膜模板（模板可改，送模型时一字不改），同时禁用「提示词重写」，避免把模板结构改坏
- **白膜「保留原始声音」**：默认开，成片贴回参考视频的原音轨；关掉就用模型自己生成的声音
- **白膜「自动时长」**：勾上后输出时长 = 参考视频真实长度（可以超过 15 秒）。软件自动**等分切段 → 逐段生成 → 拼接 → 叠回原音 → 按原时长裁尾**，长片一条龙跑完，不用自己切
- **分镜网格视图**：分镜脚本支持**网格 / 列表**双视图（标题栏图标切换，记住你的选择），镜头多时一屏看全；缩略图用 ffmpeg 抽帧并缓存，来回切不闪。「添加镜头」移到标题栏，可选插入位置，提示词 / 状态 / 视频一起挪，不会错位
- **视频历史不再限量**：每个镜头的所有历史版本单列排开、上下滚动，出完自动滚到最新一版；只加载可视区、内存里最多留 10 个，镜头再多也不卡
- **特殊格式视频不再黑框**：HEVC / H.265（手机拍的常见）在当前播放器解不出画面时，自动抽首帧当封面并提示「该视频无法解码播放」；**能正常播放的视频不做任何额外解码**，点开预览、播放都不再额外卡
- **闪退更好查**：主进程日志改为同步落盘，闪退前最后几条不会丢；显存不足时按你显卡的总容量计算阈值并**真的拦住**（不再「等一等就崩」）；本地大模型启动健康检查超时不再当成启动成功
- **镜头朝向更稳**：分镜提示词加强了机位侧位与人物朝向约束，连续镜头的左右关系、视线方向更一致
