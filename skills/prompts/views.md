## 角色与任务

本规范是「变体派生」功能的指令来源（视角变体 = 三视图；装扮变体 = 换装）。它不承担一次大模型生成任务 —— 变体派生是一条**编辑动作**，不是一次写作：程序读走「## 兜底默认」里的整行文案，拼上该角色卡自己的负向词，直接发给生图模型。

要守住的边界是：**指令只描述「要变的那个维度」，绝不复述人物长什么样**。人物的一切外观（脸、发型、头饰、服装、配饰、鞋履）都由参考图提供 —— 这正是编辑通道与文生图的根本区别，也是同一套指令能服务任意角色的原因。

## 适用范围

约束两件事：

1. **角色模块「生成 3 视图」开关打开时，侧面 / 背面这两张图怎么让模型把身体转过去**（读 侧面 / 背面 / 公共约束）。
2. **装扮变体卡的指令怎么让模型只换服装**（读 换装 / 换装约束）。装扮变体的图**不自动派生** —— 走编辑通道的前提是「有一张主体卡定妆图当参考」，参考图 = 主体卡当前选中的那张。有两条产卡路径，**共用同一行换装文案**：① **自动路径**（推荐，用户不写任何提示词）：装扮清单环节（outfits.md）从本集分镜的服装记录里识别出这个角色的全部装扮，程序按 `主体--装扮名` 自动建卡，并把识别出的装束描述填进 `{装束}` —— 卡建出来就是可直接出图的完整指令；② **手动路径**：用户在主体卡的派生弹窗里选「装扮变体」、只填装扮名，卡上预填的指令里 `{装束}` 留着，用户补上服装描述后才能重出。

不管正面图怎么生成（那是 chars.md 与 promptgen.md 的职责）、不管负向词写什么（用角色卡自己的）、不管这些图之后怎么进镜头参考图区（那是分镜侧的事）。

## 核心规则

- **只说视角，不说外观**。不要出现「大红喜服」「凤冠」「西装」这类具体服装配饰 —— 那是参考图的职责，写死了换个角色就串味（实测里必须改掉模特专属服饰词才通用）。
- **背景与光线一律沿用原图**。不要写「纯白色无缝背景」这类绝对背景：参考图是白底就保白底、是灰底就保灰底，由参考图决定。
- **姿态要能对上镜头**。侧面必须写清「双肩前后错开、后侧肩膀被身体遮住」，背面必须写清「完全看不到面部与五官」—— 不写清楚，模型只会转头不会转身（实测：只写「侧对镜头」得到的是回头看，双肩仍朝前）。
- **不重复主体描述**。指令越短越稳：参考图已经交代过的东西再说一遍只会引入冲突。
- **换装只说服装，不碰长相**（rev3）。换装那一句里只写这套装扮的款式 / 颜色 / 材质 / 头饰，**不要**复述脸型、发型、体态 —— 那些由参考图与「换装约束」兜住。实测（4 臂）：最难的「白 → 红大色块 + 换头饰 + 换发型」三处同改，脸依旧与基线一致。
- **换装不得改取景**。换装是换衣服，不是重拍：景别 / 构图 / 背景 / 光线都必须与原图一致，否则同一角色的不同套装扮取景不一致，下游视频拿它当参考图就对不上。
- **公共约束与换装约束的区别只有「服装」那一句**：公共约束要求「服装与配饰完全不变」（三视图用），换装约束反过来要求「服装与配饰随装扮更换、其余照旧」—— 两者**不能混用**，三视图用错会换掉衣服，装扮变体用错就什么都不会变。

## 格式与一致性

- 「## 兜底默认」里每行是 `键: 值`（半角冒号），已有的键名是 `侧面` / `背面` / `公共约束` / `换装` / `换装约束`。
- 值必须是**一整行**：读取方逐行匹配（parseFallbacks），一行里的值不会跨行拼接。键名里的半角冒号是分隔符，正文里的中文冒号不受影响。
- 「公共约束」那一行会被拼在每一条视角句后面（逗号连接），承载「保持身份与服装不变、背景随原图、半身完整入画」这类两条指令共用的兜底；「换装约束」同理拼在换装句后面。
- 增删**视角**：在这里加一行键值对，并在代码的 VIEW_NAMES 里登记同一个键名，两边必须对齐。
- **装扮变体不需要在这里登记**：它的名字来自装扮清单环节（自动路径，婚装 / 常服 / 夜行装…）或用户在派生弹窗里自己填（手动路径），程序只用 换装 / 换装约束 两行拼指令 —— 不占 VIEW_NAMES，也不会被「生成 3 视图」自动派生。
- **`{装束}` 里填的必须是「服装 + 配饰 + 头饰」的自足描述**（款式 / 颜色 / 材质）：它是编辑通道里**唯一**描述这套装扮的句子，写成「同上」「见档案」这类指代就等于没换装。装扮清单环节的 `desc` 字段（outfits.md）产出的就是这句话。

## 兜底默认

侧面: 把画面中的人物原地旋转为完全正侧面的视角：身体与头部一起转向画面右侧，只见一侧脸颊与完整的侧脸轮廓，鼻梁朝向画面右侧，双肩前后错开、后侧肩膀被身体遮住，双臂自然垂于身侧，站姿自然

背面: 把画面中的人物原地旋转为完全背对镜头的背面视角：完全看不到面部与五官，只见后脑、发型与头饰的背面，双肩左右对称展平，双臂自然垂于身侧，站姿自然

公共约束: 严格保持人物的身份长相、发型与头饰、服装与配饰完全不变，背景与光线与原图完全一致、不添加任何环境元素与道具，半身完整入画（头顶至腰胯、双手入画，不出现腿与脚）、比例正常、照片级真实非插画非CG

（下面两行服务**装扮变体**。🔴 「换装」必须排在「换装约束」之前 —— 读取方取第一条键名含「换装」的行，顺序反了会把约束句当成换装指令发出去。两个槽都是**具名占位符**：`{装扮}` 换成装扮名（婚装 / 常服 / 夜行装…），`{装束}` 换成这套装扮的服装 / 配饰 / 头饰描述。自动路径（装扮清单环节识别出来的装扮）两个槽都由程序填满；手动路径（用户在派生弹窗里只填了装扮名）`{装束}` 会留着，regenView 的花括号护栏会拦住并提示补 —— **两个槽都填满才允许发给生图模型**。）

换装: 把画面中人物的整套服装与配饰从头到脚更换为「{装扮}」：{装束}，换装后衣料质感与自然褶皱清晰、层次分明

换装约束: 严格保持人物的面部五官、脸型、妆容、表情、年龄与体态完全不变，发型除随这套装扮更换的头饰外保持不变，背景与光线与原图完全一致、不添加任何环境元素与道具，取景与构图与原图完全一致、仍是半身取景，比例正常，照片级真实，非插画非CG
