## 适用范围

本规范约束场景的设定与场景图提示词（中文书写，发给原生支持中文的图片模型）。全片是**古风真人实拍**：场景图等同于「古装剧实景布景照」，不是插画、不是动漫，也**不是「剧照」**——场景图必须是**空镜**，画面里只有环境与陈设，不出现任何人物。场景图全项目共享：同一场景在任意一集里都用同一套环境设定。

## 核心规则

- 提示词用中文书写，按固定顺序：**摄影定调 → 空镜声明 → 室内/室外 → 空间结构 → 主要陈设 → 材质细节 → 时间与光线 → 天气 → 真人化收尾**，全部为逗号分隔的短语。
- **摄影定调（开头就砸）**：第一个短语必须是摄影定调词，例：`极其逼真的古装剧实景照片，8K超高清，单反相机拍摄`。先定死「实景实拍」，再写环境。
- 🔴 **空镜声明（紧跟定调，越靠前权重越高）**：用**正面陈述**说明画面里没有人，例：`古装剧实景布景空镜，画面里空无一人，只有建筑与环境陈设`。若大模型漏写，程序会在生图前自动补「空镜必备句」。
- 🔴 **正向里禁止人物暗示词**：不得出现 `剧照`、`演员`、`人像`、`人物`、`某人在…` 这类词句。**「剧照」是场景出「人」的头号元凶**——它字面就是「戏剧 / 影视现场照片」，会把演员一起画进画面。场景的收尾词固定用 `古装剧实景布景照片，照片级真实`。
- 🔴 **正向里禁止否定式写法**：不要写 `无人物`、`不要出现人物`、`没有人物` 这类否定短语。模型对名词本身敏感、对否定不敏感，写着「人物」两个字反而更容易把人物画出来。空镜一律用上面那条**正面陈述**表达。
- **材质细节（实景感的来源）**：写真实材质与工艺——朱红木柱、青绿琉璃瓦、青砖地面、木纹与漆面、布幔与纱帘的真实褶皱，让画面有可触摸的质感，而不是平涂色块。
- **光线用摄影术语**：黄昏黄金时刻光线、温暖的阳光穿透花枝、柔和的环境阴影（可含青蓝色环境色）、高对比度、丰富的色彩、电影级调色、浅景深（背景虚化）、体积光 / 丁达尔效应。
- **真人化收尾（防动漫保险）**：结尾再强调一次 `古装剧实景布景照片，电影画面，照片级真实`。
- 忠于原文：环境设定必须来自改编稿。可在忠于原文的前提下补充合理细节（空间层次与透视、光线方向与色温、材质质感、陈设样式等），但不得与原文冲突，不得凭空添加改变剧情观感的关键元素（原文没有下雨就不要写雨天）。
- 同一场景在不同镜头中光线、色调保持一致；只有剧本明确的时间变化（例如傍晚转夜）才另立新场景名。
- 命名统一为「地点·内外-时段」（例：庭院·外-黄昏、书房·内-夜），同一地点不同时段视为不同场景。
- 负向提示词（negative）照常输出：中文书写，逗号分隔短语，**必须包含反动漫词表** `动漫，二次元，插画，绘画，3D，游戏CG，卡通，塑料感`，再加固定质量负面词（低画质、模糊、画面文字或水印、画面中出现人物）与针对该场景需要排除的元素（错误的天气、多余的现代物件等）；不得与正向提示词自相矛盾。但要说清一件事：当前生图模型 Z-Image Turbo 是蒸馏模型、采样 cfg=1，**负向提示词不参与采样**（界面已标注），所以它**解决不了**「画面出现人物」这类问题——这类要求只能靠正向的空镜声明。negative 保留是为了将来切回支持负向的工作流（如 SDXL）时立即可用。

## 档案与提示词的关系

- **场景档案（profile）是场景提示词的唯一依据**：先有档案，再由档案推导提示词。提示词只把档案翻译成摄影描述（摄影定调 → 空镜声明 → 室内外 → 空间结构 → 陈设 → 材质 → 光线 → 天气 → 真人化收尾），不得写入档案里没有任何线索的关键设定。
- 场景档案字段（固定顺序）：场景名 / 内外 / 时段 / 空间结构 / 主要陈设 / 材质细节 / 光线与色温 / 天气氛围 / **空镜声明**。档案的写法见「档案规范」（profile.md）。
- 用户在卡片上改了档案 → 该卡出现「档案已改 · 提示词待更新」提示 → 点「生成提示词」按新档案重算并覆盖；不点则沿用旧提示词。
- 用户手改过的提示词，只有在点「生成提示词」或模块级「批量生成提示词」时才会被覆盖。
- 档案改了但提示词没重算时，场景图的空镜保障照旧生效：生成前仍会自动检查并补「空镜必备句」。

## 格式与一致性

- 角色与场景的定调词核心（真人古装、8K超高清、单反相机拍摄）与收尾核心（照片级真实）必须一致，保证角色与场景是同一部真人剧的画风；但场景**不得**使用「剧照」二字。
- 提示词只描述环境与摄影风格，不写人物动作、不写镜头运动。
- 场景名一经确定不要改名，改名会导致已生成的场景图与新名字对不上。
- 若场景出图偏「假」或偏插画：把开头定调词换成 `单反相机拍摄的古装剧实景布景照`，并检查反动漫负向词是否写全。
- 若出图里仍然有人物：① 检查正向有没有 `剧照 / 演员 / 人像` 这类词，有就删掉；② 把空镜声明提到最前面；③ 确认这次不是「图生图」——底图里带人会被继承下来，需要先取消选中底图、重新文生图。

## 兜底默认

大模型未给出场景提示词时，程序使用下面的兜底模板：

场景: 极其逼真的古装剧实景照片，8K超高清，单反相机拍摄，古装剧实景布景空镜，画面里空无一人，只有建筑与环境陈设，空间层次与透视分明，真实材质纹理，黄昏黄金时刻光线，柔和环境阴影，浅景深背景虚化，电影级调色，照片级真实
