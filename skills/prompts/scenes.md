## 适用范围

本规范约束场景的设定与场景图提示词（中文书写，发给原生支持中文的图片模型）。全片是**{{S.styleName}}**：场景图等同于「{{S.sceneRefKind}}」，不是插画、不是动漫，也**不是「剧照」**——场景图必须是**空镜**，画面里只有环境与陈设。场景图全项目共享：同一场景在任意一集里都用同一套环境设定。

## 核心规则

- 提示词用中文书写，按固定顺序：**摄影定调 → 空镜声明 → 室内/室外 → 空间结构 → 主要陈设 → 材质细节 → 时间与光线 → 天气 → 真人化收尾**，全部为逗号分隔的短语。
- **摄影定调（开头就砸）**：第一个短语必须是摄影定调词，例：`{{S.startScene}}`。先定死「实景实拍」，再写环境。
- 🔴 **定调词里禁止出现任何摄影器材 / 拍摄设备的名字**：不得写 `{{S.equipStrip}}` 这类词——图片模型会把它们当成**画面内容**照着画（提示词里写了相机，画面里就真的出现一台相机或一个举着相机的人）。真实感只能靠**风格与质感词**表达：`实拍质感`、`照片级真实`、`{{S.colorGrade}}`、`8K超高清`、`真实材质纹理`。
- 🔴 {{S.sceneCompRule}}
- 🔴 **空镜声明（紧跟定调，越靠前权重越高）**：用**纯正向陈述**，只罗列画面里**有什么**，例：`{{S.keeper}}`。若大模型漏写，程序会在生图前自动补「空镜必备句」；程序在发送前还会把老提示词里带「人」字的旧式空镜陈述改写成这条纯正向陈述。
- 🔴 **正向里禁止人物暗示词**：不得出现 `剧照`、`演员`、`人像`、`人物`、`某人在…` 这类词句。**「剧照」是场景出「人」的头号元凶**——它字面就是「戏剧 / 影视现场照片」，会把演员一起画进画面。场景的收尾词固定用 `{{S.endScene}}`。
- 🔴 **正向里禁止否定式写法**：不要写 `无人物`、`不要出现人物`、`没有人物` 这类否定短语。模型对名词本身敏感、对否定不敏感，写着「人物」两个字反而更容易把人物画出来。**空镜陈述里只要出现「人」字就不合格**——不论是「不要有人」式的否定，还是「空旷得连一个影子都见不到」式的描写，句子里的「人」字本身就会把人生成出来。空镜一律用上面那条**纯正向陈述**表达。
- 🔴 **画面里的确切文字必须先写进档案、再原样搬进提示词**：凡带字的载具——{{S.exSign}}——都要在档案的「主要陈设」里写明**确切文字**，提示词里再**原样搬用**，写成独立短语（载体 + 「文字」 + 字数 + 书体）。通用写法与反例见「生图提示词规范」（promptgen.md）。
- **材质细节（实景感的来源）**：写真实材质与工艺——{{S.materialSamples}}、真实的纹理方向与表面反光、布幔与纱帘的真实褶皱，让画面有可触摸的质感，而不是平涂色块。🔴 材质只写**建筑 / 物件 / 环境**的材质，**不写衣物类词**（`衣物`、`服装`、`布料贴身`、`衣褶` 这类）——衣物词会召唤出穿衣服的人；布幔、帷幔、旗帜这类**陈设织物**可以写，那是环境不是人。
- **光线用摄影术语**：{{S.lightSamples}}、{{S.lightAdd}}、{{S.colorGrade}}；景深与构图一律照上一条的构图守则办（守则里说写 `全景深` 就写 `全景深`，说允许浅景深就用浅景深）。
- **真人化收尾（防动漫保险）**：结尾再强调一次 `{{S.endSceneFilm}}`。
- 忠于原文：环境设定必须来自改编稿。可在忠于原文的前提下补充合理细节（空间层次与透视、光线方向与色温、材质质感、陈设样式等），但不得与原文冲突，不得凭空添加改变剧情观感的关键元素（原文没有下雨就不要写雨天）。
- 🔴 **时段推进不改场景名、不另立新场景（rev12 硬规则）**：时段（日 / 黄昏 / 夜）是光线条件不是场景——同一地点全项目**只建一条档案、只出一张空镜参考图**；「日转黄昏转夜」的光线变化由分镜层每镜的连续性状态（时段维度）逐镜控制，不改场景名、不复制档案。场景图按档案「基准时段」的光线出图。
- 命名统一为「地点·内外」（例：{{S.placeSamples}}），**时段不进场景名**，严禁「庭院·外-黄昏」这类带时段尾巴的名字。
- 负向提示词（negative）照常输出：中文书写，逗号分隔短语，**必须包含反动漫词表** `{{S.antiStyleWords}}`，再加固定质量负面词（低画质、模糊、乱码文字、错误文字、水印）与针对该场景需要排除的元素（画面中出现人物、错误的天气、{{S.extraExclude}}等）；不得与正向提示词自相矛盾。注意：负向里排除的是**乱码文字 / 错字**，不是文字本身——画面里该有字的地方必须真的有字。但要说清一件事：当前生图模型 Z-Image Turbo 是蒸馏模型、采样 cfg=1，**负向提示词不参与采样**（界面已标注），所以它**解决不了**「画面出现人物」这类问题——这类要求只能靠正向的空镜声明。negative 保留是为了将来切回支持负向的工作流（如 SDXL）时立即可用。

## 档案与提示词的关系

- **场景档案（profile）是场景提示词的唯一依据**：先有档案，再由档案推导提示词。提示词只把档案翻译成摄影描述（摄影定调 → 空镜声明 → 室内外 → 空间结构 → 陈设 → 材质 → 光线 → 天气 → 真人化收尾），不得写入档案里没有任何线索的关键设定。
- 场景档案字段（固定顺序）：场景名 / 内外 / **基准时段**（该场景最常出现的时段，空镜参考图按它出图） / 空间结构 / 主要陈设 / 材质细节 / 光线与色温 / 天气氛围 / **空镜声明**。档案的写法见「档案规范」（profile.md）。
- 用户在卡片上改了档案 → 该卡出现「档案已改 · 提示词待更新」提示 → 点「生成提示词」按新档案重算并覆盖；不点则沿用旧提示词。
- 用户手改过的提示词，只有在点「生成提示词」或模块级「批量生成提示词」时才会被覆盖。
- 档案改了但提示词没重算时，场景图的空镜保障照旧生效：生成前仍会自动检查并补「空镜必备句」。

## 格式与一致性

- 角色与场景的定调词核心（{{S.styleCore}}）与收尾核心（照片级真实）必须一致，保证角色与场景是同一部真人剧的画风；但场景**不得**使用「剧照」二字。
- 提示词只描述环境与摄影风格，不写人物动作、不写镜头运动、不写摄影器材（`{{S.equipStrip}}` 一律不写）。
- 场景名一经确定不要改名，改名会导致已生成的场景图与新名字对不上。
- 若场景出图偏「假」或偏插画：把开头定调词换成 `{{S.startSceneAlt}}`，并检查反动漫负向词是否写全。
- 若出图里仍然有人物：① 检查正向有没有 `剧照 / 演员 / 人像` 这类词，有就删掉；② 把空镜声明提到最前面；③ 确认这次不是「图生图」——底图里带人会被继承下来，需要先取消选中底图、重新文生图；④ 检查正向有没有带「人」字的空镜写法（程序发送前也会自动改写成纯正向陈述）。
- 若出图里出现了拍摄设备或拍摄者：检查正向有没有 `{{S.equipStrip}}`、`拍摄` 这类字眼，全部删掉，改用 `实拍质感 / 照片级真实 / {{S.colorGrade}}` 表达真实感。
- 若出图里的文字是乱码 / 错字 / 少笔画（{{S.exSign}} 都算）：按「生图提示词规范」（promptgen.md）的画面内文字通用规则处理——① 把文字短语写得更靠前、更明确（载体 +「文字」+ 字数 + 书体）；② 同一提示词多抽几张择优；③ 仍不行则先生成**无字载具**、再后期贴字。

## 兜底默认

大模型未给出场景提示词时，程序使用下面的兜底模板：

场景: {{S.startScene}}，{{S.keeper}}，大远景全景空景，空间层次与透视分明，真实材质纹理，{{S.lightMain}}，{{S.lightAdd}}，全景深远近景物都清晰，{{S.colorGrade}}，照片级真实
负向: {{S.antiStyleWords}}，低画质，模糊，乱码文字，错误文字，水印，手部畸形，肢体错误，五官崩坏
器材词: {{S.equipStrip}}
