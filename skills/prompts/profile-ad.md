## 本片体裁：广告 / 品牌短片（以下规则覆盖上文）

### 主体可能是产品而不是人

产品当主角时，按上面的方法照样建一条档案（它要出一张干净的参考图，走的是同一条链路），但字段改写为**产品维度**：

```
名称 / 品类 / 外观与配色 / 材质与反光 / 品牌标志与文字 / 重点局部 / 依据
```

- 名称用脚本里的固定称谓（例：`V9X`），全片逐字一致。
- 外观与配色：车身颜色、漆面质感、轮毂样式、内饰配色——写具体到能拍。
- 材质与反光：金属漆的镜面反光、镀铬件的高光、皮革的哑光颗粒。
- 品牌标志与文字：标志位置 + **确切文字**（型号、车尾标、方向盘标），写法见上文「带字载具」那一条。
- 重点局部：列出 3-5 处必须单独出镜的细节（车灯纹理、轮毂、缝线、按键），下游会据此给特写镜头。
- 🔴 不适用于产品的字段（性别 / 年龄段 / 身形体态 / 脸型骨架 / 发型发饰 / 妆容 / 胡须）**整行省略**，不要写「未知」「不适用」「无」——空字段会让提示词里冒出「无性别」这类胡话。

### 单主体：差异化规则自然豁免

- 「任意两个角色至少 3 个维度不同」这条**只在同一批里有 ≥2 个人物主体时才适用**。全片只有一个产品、或只有一个人物时，不要为了凑这条规则硬造一个配角出来。
- 识别锚点同理：产品主体的锚点就是它的**固定局部特征**（车灯形状、徽标位置、漆色），写在「重点局部」里即可，不需要等同于人物的「脸上那个疤」。

### 一条空间一条档案，名字必须对得上

- 🔴 **一条空间 = 一条档案**：同一支片子里，**地点表述不同的段落各建一条**（例：花海公路·外 / 湖岸公路·外 / 山林弯道·外 / 雪原公路·外）。它们是四个不同的可拍空间、各出一张空镜图；合成一条的后果是下游只画得出其中一个地点，其余地点的场景提示词全无依据。
- 🔴 **档案名必须与分镜里用到的名字逐字一致**：段落主空间的档案按脚本第五部分的段落头取名，一字不差（含 `·外` 后缀）；脚本第三部分为车厢内等介质空间单列的那种（例：`座舱·内`）照抄脚本里的写法。差一个字，程序就判「有镜头没档案」，那条镜头只能退化成通用兜底的空镜提示词。
- 🔴 **同一支片子里若还有别的介质空间**（车厢内、机舱、船舱、电梯轿厢、隧道内这类与主空间不同的封闭 / 半封闭空间），**也要为它建一条**（例：`座舱·内`——真皮质感与内饰配色、中控屏与指示灯的点亮状态、天窗与出风口、内饰光照色温）。主空间与介质空间是两个完全不同的画面，只写主空间那条会让介质空间里的镜头拿主空间的空镜去生成。这类档案没有自己的段落头，是被段落内部的「车内视角」镜头引用的——不要把它的名字改成 `·外` 或省略。
- **只有画面要素基本一致的段落才共用一条档案**（例：同一条街的清晨与深夜——空间结构、陈设、材质、天气四项都没变，只是光线变了），把推进写在「光线与色温」这一行里。判断「是不是一条」的标准是**画面要素整体变没变**（空间结构 + 主要陈设与背景 + 材质细节 + 天气），不是天色变没变。
- 🔴 **季节更替 ≠ 时段推进（rev4 硬规则）**：同一段路，春天是花海、夏天是梧桐树荫、秋天层林铺落叶、冬天积雪覆盖——**画面要素整体换了，就是四个不同的场景**，必须各建一条档案、各取一个能区分得开的名字（用该季节最有辨识度的景物命名，例：`花海公路·外` / `梧桐荫公路·外` / `层林公路·外` / `雪原公路·外`）。合成一条的后果是**四季共用一张空镜参考图**，只有一个季节画得出来（实测 H10：脚本 §三 声明 5 条、下游只落地 1 条，夏 / 秋 / 冬 三段的场景提示词全无依据）。同理，晴天转大雪这类**天气性质的整体改变**也算不同的场景。
- 🔴 **名字里不许用括号加限定词**：`花海公路·外（春）` ×、`座舱·内（全片共用）` × —— 季节与用途说明要写进档案正文，名字里只留「地点·内外」，且必须与脚本第五部分的段落头**逐字一致**。
- 空镜参考图只画该场景**最常出现的时段**那一版（「基准时段」），其余时段的光线由分镜层每镜的连续性状态控制。

### 旁白与字卡不是主体

脚本里的 `旁白：「…」`、`字卡：「…」` 是声音，**不要**为它们建任何档案。品牌 slogan 与型号属于「画面里会出现的确切文字」，写进产品的「品牌标志与文字」或场景的「主要陈设」。
