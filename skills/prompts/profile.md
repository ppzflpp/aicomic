## 适用范围

本规范约束角色档案（characters[].profile）与场景档案（scenes[].profile）的内容写法。档案写**事实与设定**，提示词写**摄影描述**，两者分工不能混：档案里不写光线、镜头、画质这类摄影术语；提示词里不得出现档案中没有任何线索的关键设定。全片为**{{S.styleName}}**，{{S.worldRule}}。

## 核心规则

### 第一步：点名（穷举，不遗漏也不臆造）

- 扫改编稿，凡满足任一条就建立档案：① 有台词的人（对白冒号前的人名）② 被其他角色直接称呼的人 ③ 有独立动作或表情描写的人。
- 只作为环境一部分出现的无名群体（行人、宾客、士兵、众人）**不单独建档**；需要出现在画面里时，在镜头描述里写「群像」。
- 姓名沿用原文；原文只有称谓没有姓名时（老夫、店家、崔兄、师父），用该称谓作为 name，全片逐字一致。
- 已经建档的角色在其他集再次出现时，**沿用它原有的档案**，不要重新设计一套外观。

### 第二步：从台词反推身份（剧本没写外貌时的唯一依据）

- 剧本常常只给台词、不给外貌。此时身份线索按优先级取：① 自称与他称（{{S.worldTerms}}）② 对谁用什么语气（上下级、亲疏、敌友）③ 用词与句式（文言、俚俗、行业用语）④ 所处场景与随身物件暗示的职业。
- 只要能读出年龄带、性别、身份、地位、职业，就**必须**写进档案。例：{{S.roleExamples}}。
- 🔴 **外貌特征分两区对待（rev5 硬规则，防「全员同一张脸」）**：
  - **硬约束区**：原文 / 台词**明确写了**的外貌与状态特征（性别、伤疤、光头、独眼、白发、长短发、胖瘦……）——逐字照写，一个字不许改、不许省，设计自由区不得覆盖它们；
  - **设计自由区**：某维度在原文里**找不到任何线索**时，**不许写中庸安全词**（「五官端正」「五官立体」「气质出众」「容貌清秀」这类等于没写，模型只会把它们画成同一张脸），必须按下面的「身份→外形方向表」**主动设计一个具象的、可直接拍摄的设定**——写清脸型、眉眼鼻唇、胡型、发型长度与束法、体型、肤色、服装主色调中的至少 3 项，并保证与本批其他角色错开（见第三步）。
- **身份→外形方向表**（设计自由区的取词方向，保证补写「像这个人」而不是随机发挥）：
  {{S.lookTable}}
  表里没有的身份按同一思路自推：先定位年龄带与阶层，再挑 2-3 个与身份自洽、且与其他角色不重复的具象特征。
- **按戏份定设计力度**：主人公与重要配角 → 脸部至少 3 处具象特征，且**识别锚点必须至少有 1 个长在脸 / 头上**（疤、痣、断眉、胡型、发色发型），不许全靠配饰道具；功能性配角（只出场一两场的路人甲、摊主乙）→ 1-2 处锚点即可，不必重重加码。
- 实在读不出身份的边缘人物：年龄段 + 体态 + 服装材质给一个与同批角色**错开**的明确设定，同样**不许留空**、不许写「未知」，宁可有明确设计感也不要空着让画师随机。

### 第三步：差异化设计（硬约束，防「全员同一张脸」）

- 同一批档案里，**任意两个角色至少在 3 个维度上明显不同**，且其中至少 1 个是**剪影级差异**（身形高矮胖瘦、发型长度与束法、{{S.exWardrobe}}）。
- 可分配的维度：年龄段、身形体态、脸型骨架、发型与长度、{{S.exWardrobe}}、服装主色系、服装款式、面料纹样、配饰、手持道具（本世界的可用形态维度由这一串决定，合计不少于 12 项）。
- 每个角色必须有 **1 个一句话能复述的识别锚点**（{{S.exAnchor}}），写在「配饰道具」一行。
- 主色按角色分配，同片不撞色：{{S.exPalette}}。
- 任务里若给出「本项目已有角色」的档案，新角色的上述维度必须与它们**错开**。
- 禁止：所有角色共用一套默认描写（年轻英俊、五官立体、白衣）；禁止用「相似 / 同样风格」描述两个角色。

### 第四步：字段与格式

- 每行一个字段，格式「字段名：值」，冒号用**全角**「：」；不写 Markdown 标题、不写编号、不留空行。
- 角色档案字段（固定顺序）：姓名 / 身份 / 性别 / 年龄段 / 身形体态 / 脸型骨架 / 发型发饰 / 胡须 / 服装 / 配饰道具 / 主色调 / 神态 / 依据
- 🔴 「服装」「配饰道具」写的是**全片基线装束**（最常出现、最稳定的一套），不是某一镜的瞬时状态：不得把剧情里的变化写进基线（{{S.exState}}）。剧情中的状态变化属于分镜层的「连续性状态」——每镜各自记录当时的状态，变化的那一镜标出变化点。同一件东西**变了之后**的样子同样只写在分镜层，档案里只保留基线。
- 🔴 角色档案不能带场景元素：不得写「身旁是什么建筑、什么庭院」这类环境描写（角色图一旦带环境，生成视频时会把环境一起学进去）。
- 场景档案字段（固定顺序）：场景名 / 内外 / 基准时段 / 空间结构 / 主要陈设 / 材质细节 / 光线与色温 / 天气氛围 / 空镜声明（「基准时段」写该场景最常出现的时段，空镜参考图按它出图；时段是光线条件不是场景——时段推进不改场景名、不另立档案，光线变化由分镜层每镜的连续性状态控制）
- 🔴 **画面里会出现的确切文字，必须原样写进档案**：凡是带字的载具——{{S.exSign}}——都要写明**载体 + 确切文字（用「」括起）+ 字数 + 书体/字体**，例如 {{S.exText}}。场景写进「主要陈设」一行；角色身上的字（校名 / 绣字 / 番号）写进「服装」或「配饰道具」一行。**严禁**只写「刻着字」「有字迹」「写着标语」这种含糊说法——提示词只能照抄档案，档案含糊，画面里必然是乱码或错字。
- 「依据」一行写这条档案的线索来源（谁怎么称呼他、哪句台词），便于人工核对；属于合理补写的部分注明「（剧本未提及，按身份合理设定）」。

### 第五步：输出前自检

- 把所有角色的档案并排检查：去掉名字后，任意两个角色的描述会不会让人认成同一个人？会 → 重做，加大区分维度。
- 场景档案必须含「空镜声明」一行，用**纯正向**陈述（例：画面内只有建筑、陈设与自然环境），**不得**出现「剧照 / 演员 / 人像」这类召人词，也不要用否定式写法（不要出现人物 / 没有人物）；并且这一行的句子里**一个「人」字都不要有**——带「人」字的说法同样会把人生成出来。
- 档案里每一处带字的载具（{{S.exSign}}）都要核对：文字内容、字数、书体是不是都写全了，写的字**是不是你真的想让画面里出现的那几个字**。
- 档案只写设定，不写动作、不写剧情评价。

## 格式与一致性

- 角色与场景的档案是全片共享的：同一名字在任何一集都对应同一份档案，改名等于换人。
- 档案与提示词一一对应：一张卡只有一份档案、一份正向提示词、一份负向提示词。
- 用户在界面上手改过档案后，卡片会提示「档案已改 · 提示词待更新」，点「生成提示词」按新档案重算；不点则沿用旧提示词。
