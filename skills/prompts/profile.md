## 适用范围

本规范约束角色档案（characters[].profile）与场景档案（scenes[].profile）的内容写法。档案写**事实与设定**，提示词写**摄影描述**，两者分工不能混：档案里不写光线、镜头、画质这类摄影术语；提示词里不得出现档案中没有任何线索的关键设定。全片为**古风真人实拍**，档案里出现的时代与物件必须属于古装背景。

## 核心规则

### 第一步：点名（穷举，不遗漏也不臆造）

- 扫改编稿，凡满足任一条就建立档案：① 有台词的人（对白冒号前的人名）② 被其他角色直接称呼的人 ③ 有独立动作或表情描写的人。
- 只作为环境一部分出现的无名群体（行人、宾客、士兵、众人）**不单独建档**；需要出现在画面里时，在镜头描述里写「群像」。
- 姓名沿用原文；原文只有称谓没有姓名时（老夫、店家、崔兄、师父），用该称谓作为 name，全片逐字一致。
- 已经建档的角色在其他集再次出现时，**沿用它原有的档案**，不要重新设计一套外观。

### 第二步：从台词反推身份（剧本没写外貌时的唯一依据）

- 剧本常常只给台词、不给外貌。此时身份线索按优先级取：① 自称与他称（老夫、小生、在下、末将、卑职、贫僧、弟子、师父、娘子）② 对谁用什么语气（上下级、亲疏、敌友）③ 用词与句式（文言、俚俗、行业用语）④ 所处场景与随身物件暗示的职业。
- 只要能读出年龄带、性别、身份、地位、职业，就**必须**写进档案。例：「老丈」→ 六十岁上下、布衣老者；「末将」→ 中年武将、铠甲在身；「贫僧」→ 僧人、剃度、僧袍。
- 实在读不出来的字段**不许留空、不许写「未知」**：给一个不与原文冲突、可直接拍摄的中庸设定（年龄段、体态、服装材质），宁可有明确设计感也不要空着让画师随机。

### 第三步：差异化设计（硬约束，防「全员同一张脸」）

- 同一批档案里，**任意两个角色至少在 3 个维度上明显不同**，且其中至少 1 个是**剪影级差异**（身形高矮胖瘦、发型长度与束法、冠帽、胡须、外披轮廓）。
- 可分配的 12 个维度：年龄段、身形体态、脸型骨架、发型与长度、发饰冠帽、胡须、服装主色系、服装款式、面料纹样、外披披风、配饰、手持道具。
- 每个角色必须有 **1 个一句话能复述的识别锚点**（左颊一道旧疤、断眉、常年握着的酒葫芦、素黑无纹披风、铜环宽腰带），写在「配饰道具」一行。
- 主色按角色分配，同片不撞色：主人公暖金或月白，对立方暗紫墨黑，辅助角色青灰或褐。
- 任务里若给出「本项目已有角色」的档案，新角色的上述维度必须与它们**错开**。
- 禁止：所有角色共用一套默认描写（年轻英俊、五官立体、白衣）；禁止用「相似 / 同样风格」描述两个角色。

### 第四步：字段与格式

- 每行一个字段，格式「字段名：值」，冒号用**全角**「：」；不写 Markdown 标题、不写编号、不留空行。
- 角色档案字段（固定顺序）：姓名 / 身份 / 性别 / 年龄段 / 身形体态 / 脸型骨架 / 发型发饰 / 胡须 / 服装 / 配饰道具 / 主色调 / 神态 / 依据
- 场景档案字段（固定顺序）：场景名 / 内外 / 时段 / 空间结构 / 主要陈设 / 材质细节 / 光线与色温 / 天气氛围 / 空镜声明
- 「依据」一行写这条档案的线索来源（谁怎么称呼他、哪句台词），便于人工核对；属于合理补写的部分注明「（剧本未提及，按身份合理设定）」。

### 第五步：输出前自检

- 把所有角色的档案并排检查：去掉名字后，任意两个角色的描述会不会让人认成同一个人？会 → 重做，加大区分维度。
- 场景档案必须含「空镜声明」一行，用正面陈述（画面里空无一人），**不得**出现「剧照 / 演员 / 人像」这类召人词，也不要用「无人物」这种否定写法。
- 档案只写设定，不写动作、不写剧情评价。

## 格式与一致性

- 角色与场景的档案是全片共享的：同一名字在任何一集都对应同一份档案，改名等于换人。
- 档案与提示词一一对应：一张卡只有一份档案、一份正向提示词、一份负向提示词。
- 用户在界面上手改过档案后，卡片会提示「档案已改 · 提示词待更新」，点「生成提示词」按新档案重算；不点则沿用旧提示词。
