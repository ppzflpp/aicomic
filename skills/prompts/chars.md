## 适用范围

本规范约束角色的外观设定与角色图提示词（中文书写，发给原生支持中文的图片模型）。全片是**{{S.styleName}}**：角色图等同于「{{S.charRefKind}}」，不是插画、不是动漫、不是 3D 渲染。角色图全项目共享：同一角色在任意一集里都用同一套外观。

## 角色命名（跨集共享的唯一键）

名字是角色在全项目里的**唯一标识**，它同时决定：图片目录名（`assets/characters/<名字>/`）、分镜里的 `chars` 字段、对白「人名：台词」归属于谁、参考图归属哪个角色。**同一个名字必须处处一致** —— 名字差一个字，参考图就会挂到别人头上（成片表现为串脸、换脸）。

- 🔴 **同一人物的不同年龄 / 形态 / 重大状态 = 两个不同角色**，必须分别提取、分别命名，格式为 `基础名-限定词`。例：剧本里少年与老年各出现过的李白 → 提取成 `李白-少年` 与 `李白-老年` 两条；长期女扮男装的苏晚 → `苏晚-男装`。
- 形态单一的人物**只用本名**：`张伯`、`刘婶`，不要画蛇添足加后缀。
- 🔴 **剧情里再次出现的人物，若用户消息里给出了「本项目已存在的角色」清单，必须原样沿用清单里的名字**：不要另起新名、不要简写、不要调换词序（不能把 `李白-少年` 写成 `少年李白` 或 `李白`）。
- 名字用中文，不含空格与标点；`-`（半角短横）只用于分隔「基础名-限定词」，是唯一允许的连接符。
- 拿不准某形态该不该单列时：**只要剧本里能看出属于不同年龄或不同造型阶段，就单列成两个角色**。

## 核心规则

- 提示词用中文书写，按固定顺序：**摄影定调 → 年龄性别 → 脸型五官 → 妆容 → 皮肤与发丝 → 服装材质 → 面部基线 → 光线与镜头 → 取景（半身像） → 真人化收尾**，全部为逗号分隔的短语，不要写成整句。
- 🔴 **「年龄性别」短语一律写「看得见的阶段」，不写年数（rev14）**：写 `少女`／`少年`／`青年男子`／`中年妇人`／`六旬老者`／`二十余岁`／`三十出头` 这类阶段词，**不要**写 `十六岁`、`23岁` 这样的年数。两条理由：① **年数不是画面信息**——画不出「16」与「17」的差别，模型只能按自己理解的岁数去猜脸，反而比「少女」更不可控；② **低龄年数在生图模型上会踩安全策略**（提示词里明写低龄数字容易被过滤，或把整张脸往幼稚化带），剧集里出现少年角色时尤其要避开。⚠️ 档案里的「年龄段」**照事实写**（它是设定事实，也是差异化矩阵的维度之一），**只在这一层把年数换成阶段词**；阶段词仍要与档案一致（档案是十六岁的少女，就写 `少女`，不许写成 `成熟女性`）。
- **「脸型五官 / 妆容」两段要具体到能画出来（配合 rev7/rev10）**：`颧骨微高`、`下颌线条利落`、`眼尾略挑`、`唇薄而色淡` 这类**可见结构**才有效；`五官立体`、`气质出众` 属于万金油，等于什么都没说。档案只写了万金油词时，按档案规范（profile.md）的「身份→外形方向表」给出**一个**不与档案冲突的具体化描述——注意是**给出一个明确值**，不要写「或许是杏眼，也可能是丹凤眼」这种二选一：图片模型收到的画面必须唯一（本项目的铁律是「档案是唯一依据、不许编」，生图这一步不许把不确定性带进去）。
- 🔴 **「面部基线」这一环照抄档案 + 固定收口词，不做自由发挥（rev17）**：只写角色档案「面部基线」字段里的**可拍的固定特征**（眼神走向、眉形带来的惯常神情、嘴角固定弧度、面部长驻痕迹），后面接一句**全片统一的收口词** `神情平和，目光自然平视前方`。🔴 **禁止写入三类东西**：① 情绪状态（`神色疲惫`／`焦急`／`神情安详`——情绪逐镜变化，角色图上写死某个情绪就会与大多数镜头冲突）；② 动作与行为（`微微摇头`／`手指紧攥衣角`／`咳嗽`／`动作颤抖`——属于分镜层的 action 与下游视频提示词）；③ 性格与价值判断（`唯利是图`／`言语中透着命令`——画不出来，属于人设）。档案里若混进了这三类，**按 profile.md 对该字段的定义改写后再用，不要原样翻译**——照抄会把一副剧情表情钉死在角色图上，下游视频拿它当外观参考、每帧都端着它。
- **摄影定调（开头就砸）**：第一个短语必须是摄影定调词，例：`{{S.startChar}}`。先给模型下死命令「这是拍照，不是画画」，后面所有描写才站得住。
- 🔴 **定调词里禁止出现任何摄影器材 / 拍摄设备的名字**：不得写 `{{S.equipStrip}}` 这类词——图片模型会把它们当成**画面内容**照着画（提示词里写了相机，角色图里就可能多出一台相机或一条相机背带）。真人感只能靠**风格与质感词**表达：`实拍质感`、`照片级真实`、`{{S.colorGrade}}`、`8K超高清`、`浅景深（背景虚化）`、`真实皮肤纹理与毛孔`、`真实发丝`。
- **物理细节（真人感的唯一来源）**：必须写真实皮肤纹理、毛孔、真实发丝——这些是插画里绝对不存在的东西，写出来才能把模型逼到真人档位。
- **服装写材质、不写文学词**：不要写「气质孤傲潇洒」这类无法转成画面的形容词；改写布料与工艺——{{S.exFabric}}、真实的布料褶皱与光泽。
- **光线与镜头用摄影术语**：{{S.lightMain}}、{{S.lightAdd}}、浅景深（背景虚化）、{{S.colorGrade}}、自然光。
- **真人化收尾（防动漫保险）**：结尾再强调一次 `{{S.endCharFilm}}`，把模型最后的注意力重新锁死在真人质感上。
- 忠于原文：所有设定必须来自改编稿。可在忠于原文的前提下补充合理细节（五官比例、发型走向、服装款式/材质/颜色、配饰、面部基线等），但不得与原文冲突，不得添加原文没有的关键设定（原文没有眼镜就不要加眼镜，原文是短发就不要写长发）。
- 每个角色必须有区分度：发型发色、服装、主色调三者中至少有一项与其他角色明显不同。
- 同一角色在全片所有镜头中保持同一套外观描述，不随意更换服装（除非剧本明确换装）。
- **服装写「基线装束」，不写某一镜的状态**：档案里的服装 / 配饰道具是**全片基线**（最常出现的那套装扮），不得把剧情里的瞬时状态（{{S.exState}}）写进基线——那些属于分镜层的「连续性状态」（每镜各自记录）。
- 🔴 **角色图必须是干净的参考图（参考图会直接喂给视频模型，画面里有什么都会跟着进视频）**：
  - 纯色中灰背景（单一色调、无渐变、无纹理、无陈设、无建筑、无天空/树木等任何环境元素）；
  - 画面里只有这一个角色，单人、居中、🔴 **必须是半身像（头顶至腰胯、双手完整入画，不出现腿与脚）**、正面或四分之三侧脸，🔴 表情写「面部基线」那一环的固定神情 + 全片统一收口词 `神情平和，目光自然平视前方`（rev17：不再写「中性」——否定式表述容易出证件照式的呆滞脸，这里给一个明确值），姿态中性（站定，不做剧情动作）；
  - 只穿基线装束，不携带任何剧情道具（{{S.exProp}}…），不呈现任何剧情状态（淋雨、湿透、血污、伤痕、狼狈）；
  - 画面里不出现文字、字幕、水印、边框、道具标签。
  理由：角色图一旦带环境或剧情道具，生成视频时会整片泄漏进画面（实测：{{S.exLeak}}）。
- 单张图只画一个人，不要双人 / 多人，不要出现文字、字幕、水印。
- 每个角色除正向提示词外还要输出一条负向提示词（negative），中文书写，逗号分隔短语，**必须包含反动漫词表** `{{S.antiStyleWords}}`，再加固定质量负面词（低画质、模糊、画面文字或水印、手部畸形、肢体错误）与针对该角色需要排除的元素（{{S.extraExclude}}、错误服饰风格等）；不得与正向提示词自相矛盾，也不要堆砌与该角色无关的负面词。

## 档案与提示词的关系

- **角色档案（profile）是角色提示词的唯一依据**：先有档案，再由档案推导提示词。提示词只把档案翻译成摄影描述（摄影定调 → 年龄性别 → 脸型五官 → 妆容 → 皮肤发丝 → 服装材质 → 面部基线 → 光线镜头 → 取景 → 真人化收尾），不得写入档案里没有任何线索的关键设定（档案没提疤痕就不要写疤，没提发型就不要换发型）。
- 档案的写法与字段见「档案规范」（profile.md）：人物必须穷举、身份从台词反推、任意两个角色至少 3 个维度不同（含 1 个剪影级差异）并各有 1 个识别锚点。
- 用户在卡片上改了档案 → 该卡出现「档案已改 · 提示词待更新」提示 → 点「生成提示词」按新档案重算并覆盖；不点则沿用旧提示词。
- 用户手改过的提示词，只有在点「生成提示词」或模块级「批量生成提示词」时才会被覆盖；重新生成分镜等其他流程不碰它。
- 批量生成提示词时，程序会把「本项目已有角色的档案摘要」一并下发，新角色必须与已有角色的外观维度错开，避免撞脸、撞色。

## 格式与一致性

- 全片共用同一套定调词与收尾词（摄影定调 + 真人化收尾），角色与场景必须统一，不能一部分真人一部分插画。
- 构图统一为宜：**纯色中灰背景 + 单人半身像（头顶至腰胯、双手完整入画）**（便于下游视频生成时当参考图；实景背景会连同环境一起被学进视频）。
- 🔴 **景别一律统一为半身像，不写「全身 / 胸像 / 七分身 / 中近景」**（rev16，2026-10-14）：取景写法一律是 `半身像（头顶至腰胯、双手完整入画，不出现腿与脚）`，位置在「光线与镜头」之后；正面图与「生成 3 视图」派生出的侧面 / 背面必须**完全同一取景**（编辑通道不锁构图、只会照文字执行，两边口径不同就一定会打架）。⚠️ 半身像看不到下装与鞋履，下游视频拿它当参考图时下半身没有依据——这是 rev16 明确接受的取舍。
- 提示词只描述外貌与摄影风格，不写动作、不写情绪、不写场景、不写镜头运动、不写剧情道具与剧情状态、不写摄影器材（`{{S.equipStrip}}` 一律不写）。
- 若出图仍偏「假」或偏插画：把开头定调词换成 `{{S.actorShot}}`——加上「演员」二字，模型调用真人脸模的概率会明显提高；负向词表一个都不能省。

## 兜底默认
