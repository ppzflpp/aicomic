## 本片体裁：广告 / 品牌短片（以下规则覆盖上文）

### 主体可能是产品而不是人

产品主体照样出一张参考图（走同一条链路，下游拿它当参考图生成视频），但提示词的**维度顺序整套换掉**：

```
摄影定调 → 品类与整体轮廓 → 配色与漆面 → 材质与反光 → 品牌标志与确切文字 → 重点局部特写 → 光线与镜头 → 收尾
```

- **摄影定调**照旧：第一个短语必须是摄影定调词（{{S.startChar}} 那一档），先给模型下死命令「这是拍照，不是画画」。
- **品类与整体轮廓**：一句话说清这是什么（例：一台中大型六座 SUV），车身比例与姿态。
- **配色与漆面**：车身颜色 + 漆面类型（金属漆 / 珠光漆 / 哑光）+ 反光特征。
- **材质与反光**：镀铬件的高光、玻璃的通透与反射、轮胎的橡胶颗粒感、皮革内饰的哑光纹理——**这就是产品的「真实感来源」**（人物的真实感来自皮肤毛孔与发丝，产品的真实感来自材质与反光，两者在提示词里的位置一样重要）。
- **品牌标志与确切文字**：位置 + 原样文字（用「」括起 + 字数 + 字体），一字不许改写。
- **重点局部特写**：档案里「重点局部」那几处，按重要性排一下，本条参考图以「整车 + 最能代表它的一处局部」为主。
- 🔴 **整套人物维度不写**：不写年龄、性别、身形体态、脸型五官、皮肤纹理、毛孔、发丝、面部基线、演员、定妆照。写了这些，模型会试图在车身上找一张脸。
- 🔴 **基座 rev17 的固定收口词同样不适用**（rev4）：`神情平和，目光自然平视前方` 那类表情短语是给**人**写的，产品主体一律不写任何与表情、情绪相关的短语——产品的收口按下面那一条走（质感 + 写实表达）。
- 🔴 **收尾词不要用人物那套**（`{{S.endChar}}` / `{{S.endCharFilm}}` 是给人物写的）。产品参考图的收尾用同一档的「质感 + 写实」表达：`实拍质感`、`照片级真实`、`{{S.colorGrade}}`、`8K超高清`，不要出现「演员」「真人」这类词。

### 参考图的要求不变（而且对产品更重要）

- 纯色中灰背景、单一色调、无渐变、无纹理、无陈设、无建筑、无天空与地面延伸；画面里只有这一件产品，居中、占画面主要比例、正面或四分之三视角；
- 🔴 **景别不套用基座的「半身像」**（rev3）：基座 chars.md 要求角色参考图是「半身像（头顶至腰胯、双手完整入画）」，那是为**人**写的（为了把脸和上半身拍清楚）；产品没有「半身」可言，**本条对本体裁无效**——产品的取景按上一条走：整车完整入镜 + 最能代表它的一处局部。人物主体（广告也有真人出镜时）仍照基座写半身像。
- 不带任何剧情状态（在雨中、带泥点、开着车门、有人坐在里面）；
- 画面里不出现文字、字幕、水印、边框——**除了产品本身的标志与型号文字**（那是产品的一部分，要写清确切文字）；
- 负向词表照旧必须含反动漫词表 `{{S.antiStyleWords}}`，再加质量负面词（低画质、模糊、水印、标志错字、比例失真）。

### 多个主体

全片只有一件产品 + 一个人物是常态：两条档案各自一条，**不要互相套维度**（人物照样写人物维度、产品照样写产品维度）。差异化规则（至少 3 个维度不同）在只有一个产品时自然豁免，不要硬造第二个产品。
