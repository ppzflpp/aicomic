## 本片体裁：广告 / 品牌短片（以下规则覆盖上文）

### 素材形态：广告脚本稿，不是分场剧本

上游给的是广告片脚本稿（创意核心 / 主体设定 / 空间与光线连续性 / **转场表** / 分场（段落）剧本），不是分场剧本文本。对应关系：

- 第五部分的「段落」就是上文说的「场次」；段落头 `段落 1：花海公路·外` 里的「地点·内外」照抄进 `shots[].scene`，**逐字复制、不带上「段落 1：」这个前缀**。
- 🔴 **连续时空只对应一个场景名**：脚本第三部分把「一段连续的旅程」写成一条空间档案时，全片所有段落都用**同一个** `shots[].scene`，`scenes[]` 也就只有**一条**。不要把每个季节 / 每个段落当成一个新场景去建档案——那不是四个场景，是同一个空间的四个时段，时段由每条镜头的 `continuity` 控制。
- 镜头正文里的描述句**不一定**各自成一镜：同一个段落里机位连续、动作连贯的几条描述（例：全景疾驰而过 → 挡风玻璃特写）属于**同一个动作单元**，合并进一条镜头的 `action`（用「随后 / 接着」衔接，景别与运镜照抄进 `camera`）。
  🔴 **这一条覆盖基座的核心规则**：基座写「动作、空间或时间发生变化就切新镜头」是**分集短剧**的粒度；本体裁按**段落**粒度执行——一段里换机位、换景别、镜头推近都不另开镜头，只有「进入下一个段落」或段落内确实有两个互不相干的画面主体时才断开。

### 声音：旁白行与字卡行

脚本里的 `旁白：「…」`、`字卡：「…」` 与 `说话人：「…」` 一样，直接写进该镜的 `dialogue` 字段，格式不变（`冒号前是发声者`，全角冒号）。

🔴 **旁白行 / 字卡行不许单独成镜（rev2 新增，本体裁最容易被违反的一条）**

脚本里 `旁白：「…」` 与 `字卡：「…」` 是**同一句文案的两种落地方式**（一个念出来、一个打在画面上）。它们**属于**那条画面镜，**不是**一镜。

- 写法：把旁白写进该段落**主力镜**的 `dialogue`（`旁白：原句`），同一句字幕写进**同一镜**的 `action`（例：`画面下方浮现白色无衬线字幕：原句`）。**一句文案 = 同一镜里的一次交代**，不许前一镜写旁白、后一镜再把同一句写成字卡。
- 输出前逐镜检查 `action`，过一遍这一问：**「这一镜里除了字幕，还有什么可拍的画面？」** 答不上来的镜头，一律并进相邻镜头，不许留下。整镜 `action` 只有一条字幕是最严重的错误之一——它没有任何画面信息，视频模型只能自由发挥，是漂移与接缝断裂的最大来源。
- 若某段落只有旁白 / 字卡、一条画面描述句都没有（罕见），把它的文案并进**相邻段落**已有镜头的 `dialogue`，不要为它单独建镜。
- 段落头下面那些「时间地点行」「转场说明行」同样不是画面，不要为它们开镜。

- `字卡` 的内容通常是品牌名 / 型号 / slogan，属于**画面文字**：写进 `dialogue` 的同时，也要在对应 `scenes[].profile` 里按「带字载具」写出确切文字（载体 + 「文字」 + 字数 + 字体）。

- 🔴 **旁白与字卡不是角色**：不要为它们在 `characters[]` 里建条目，也不要写进 `shots[].chars`。`chars` 只写真正出现在画面里的主体。为「旁白」建一张角色卡会去生成一张根本不需要的参考图。

### 🔴 转场配对（本体裁最重要的一条新增规则）

转场表里的每一条 = **一对镜头**（前一段结尾的那一条 + 后一段开头的那一条）。这一对必须：

1. **相邻**：两条镜头紧挨着，中间不许插入任何其它镜头——插一条就接不上了；
2. **同景别同机位**：两条的 `camera` 必须写出**相同的景别与机位**（例：两条都写 `挡风玻璃特写，低机位`）。下游靠这一点把它们配成一对，让前一条的末帧接上后一条的首帧；
3. **共享共同元素**：前一条的 `action` 必须**收在**那个共同元素上（例：雨刷自左向右扫过挡风玻璃，把花瓣推离，留下一道水痕）；后一条的 `action` 必须**从一个等价动作开始**，并在句首显式写出承接关系：

```
承接上一镜的雨刷动作，同一个景别与机位，雨刷继续自左向右扫过，这次推开的是暴雨的水幕。
```

4. **快照成套**：后一条的 `continuity` 里，时段 / 天气 / 环境要写成「承接上一镜的同一个……」或明确写成换季，不要含含糊糊；共同元素涉及的维度按它当下的状态写全。
5. **这一对镜头都必须有可拍的画面主体**：车、人、物件、天气都行，但不许是纯字幕镜或纯空镜——它们在成片里是**接缝**，接缝处最怕模型自由发挥。转场镜里只写一条字幕，等于把接缝交给模型随机画。

若这次切换本身就是画面里看得见的一个动作（雨刷刷过、车头穿过隧道口、后视镜里画面回溯），可以按上文规则把它标成一条 `change`。**但只有在 `action` 里真的写了那个动作时才标**——程序会检查「标了状态变化，但本镜画面动作里没有这个动作」。

### 产品当主角

- 产品要在 `characters[]` 里建一条档案：`name` 用脚本里的固定称谓，`role` 写 `产品`。档案字段改用**产品维度**：`名称 / 品类 / 外观与配色 / 材质与反光 / 品牌标志与文字 / 重点局部 / 依据`。不适用于产品的字段（性别 / 年龄段 / 胡须）**整行省略**，不要写「未知」或「不适用」。
- 🔴 **细节特写优先**：车灯纹理、轮毂反光、缝线、按键、品牌徽标这类局部，每条都要给到特写；不要全片都是远景全景——大件产品的质感全在特写里。
- **一个卖点一条镜头**：素材里写到的卖点，每一条都要有对应的**可拍**镜头（「加速快」→ 起步时背景拉成横向拖影；「隔音好」→ 车窗外雨幕模糊、车内安静特写），不要只有旁白在讲。
- 产品与人物同框时，`shots[].chars` 两个都写。

### 镜头量：按段落数算，不按字数算（rev2 重写）

- 🔴 **基座那条「每 1000 字改编稿约 8-15 个镜头」在本体裁下不适用**：它是为分集短剧写的。广告片的镜头量由**段落数**决定，与字数无关——文案写得再满，段落数不变，镜头数就不该跟着涨。
- 一条段落 = **1-2 个镜头**（默认 1 个；只有当这一段里确实存在两个互不相干、各自都能独立成图的画面主体时才给 2 个）。全片上限 = **段落数 × 1.5，向上取整**：5 段 ≤ 8 镜，8 段 ≤ 12 镜，12 段 ≤ 18 镜。
- 🔴 **算术自检（输出前必须过）**：`镜头数 ≤ 脚本总秒数 ÷ 4`（4 秒是单镜硬下限，也是基座契约里的 `dur` 下限）。例：30 秒的片子最多 7 镜；超了就说明你在把一句话切成两镜，回去合并。
- 🔴 **总时长自检**：全部镜头 `dur` 之和必须落在「脚本各段秒数之和」的 **±20%** 以内（例：脚本各段合计 30 秒 → 分镜总时长 24-36 秒）。这是最灵敏的报警器：镜头数一多，总时长必然爆。
- **不要为了「完整」把广告片拉成剧集的镜头密度**——镜头多一条，视频就多一次独立生成，漂移风险随之放大。**转场配对（见上文）是该拆的地方**；除此之外一律**合并优先**：同一段落内机位连续就并成一镜，旁白 / 字卡并进画面镜。
